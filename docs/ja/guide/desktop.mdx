Navora は、Agent の実行環境とシステム最前面の透明フローティングペットを備えたデスクトップクライアントを提供しています。**Python や依存関係を手動でインストールする必要はありません**。ダウンロードしてインストールするだけで、ローカルで AI アシスタントを実行できます。

## ダウンロードとインストール

<Card title="GitHub Releases へ" icon="download" href="https://github.com/jialexiao341-glitch/Navora/releases">
  Navora デスクトップインストーラーをダウンロード
</Card>

<Tabs>
  <Tab title="Windows">
    1. [GitHub Releases](https://github.com/jialexiao341-glitch/Navora/releases) を開き、Windows インストーラー（`Navora-Setup-*-x64.exe`）をダウンロードします。
    2. インストーラーを実行し、画面の指示に従います（インストール先を選択できます）。
    3. デスクトップまたはスタートメニューから Navora を起動します。
  </Tab>
  <Tab title="macOS">
    1. [GitHub Releases](https://github.com/jialexiao341-glitch/Navora/releases) を開き、チップに合わせて選択します：
       - Apple Silicon（M1/M2/M3/M4）：`arm64` 版をダウンロード
       - Intel：`x64` 版をダウンロード
    2. ダウンロードした `.dmg` を開き、Navora を「アプリケーション」フォルダにドラッグします。
    3. Launchpad またはアプリケーションから Navora を起動します。
  </Tab>
</Tabs>

## 自動アップデート

デスクトップクライアントには GitHub Releases を利用した自動アップデート機能が組み込まれています。新しいバージョンがあると自動的に検出・通知され、左下のメニューから手動で「アップデートを確認」して、リリースノートを確認しながらワンクリックでアップグレードできます。

## デスクトップとコマンドラインの違い

- **デスクトップクライアント**：自分の PC での個人利用に最適。システムトレイ、自動起動、フローティングペット、自動アップデートに対応。
- **コマンドラインデプロイ**：開発者やサーバーでの長期運用に最適で、カスタマイズ性が高い。詳しくは [クイックスタート](/ja/guide/quick-start) を参照。

## ブラウザからのアクセス

デスクトップクライアントは起動するとローカルでポート `9876` をリッスンし、Web コンソールそのものを表示・提供します。アプリを開いている間はブラウザで `http://localhost:9876` にアクセスしても同じ体験が得られます。

このポートが使用できない場合（Windows で Hyper-V/WSL2 に予約されている場合など）、クライアントは自動的に別のポートへフォールバックして正常に起動します。実際のポートは `run.log` の `Local access` 行で確認でき、`config.json` の `web_port` で固定することもできます。

デフォルトではこのマシンからのみアクセスできます。同じネットワーク内の他のデバイス（スマートフォンなど）から開くには、「設定 → 連携設定」でリスンアドレスを `0.0.0.0` またはこのマシンのローカル IP に変更してください（事前にアクセスパスワードの設定が必要です）。他のデバイスから開けるアドレスが下に表示されます。

## ローカルデータの保存

デスクトップクライアントのすべてのデータはお使いのマシンに保存されます（互換性維持のため `~/.cow` および `~/cow` を使用します）：

- **設定ディレクトリ**：ホームフォルダの `~/.cow`。`config.json`（モデルキーやチャネルなどの設定）のほか、ログ・キャッシュなどの実行データが含まれます。
- **ワークスペース**：デフォルトは `~/cow`。会話履歴・ナレッジベース・記憶・スキル・定期タスクなど、Agent が生成したファイルが保存されます。

クライアントをアンインストールまたはアップグレードしてもこの 2 つのディレクトリは自動削除されないため、再インストール後もデータは保持されます。完全に削除したい場合や別のデバイスへ移行する場合は、該当するフォルダを手動でバックアップまたは削除してください。
